# Fontes da interface

Inter 4.1, nos pesos regular e semibold, distribuída sob SIL Open Font License 1.1.
A licença e os avisos de copyright estão em `LICENSE` neste diretório.
Os arquivos originais foram obtidos da versão 4.1 publicada em
<https://github.com/rsms/inter/releases> (`extras/ttf/Inter-Regular.ttf` e
`extras/ttf/Inter-SemiBold.ttf`). Não foram modificados.

As fontes são incorporadas no executável para manter a tipografia nos temas
claro e escuro, sem depender das fontes instaladas no computador. As fontes
padrão do egui continuam como alternativas para caracteres ausentes.
