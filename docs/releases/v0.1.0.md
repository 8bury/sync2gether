# sync2gether 0.1.0

Primeira release para duas pessoas assistirem ao mesmo vídeo, com uma cópia local em cada PC. O anfitrião coordena a sala por TCP na rede local ou em uma VPN. O aplicativo não transmite o vídeo.

- Reprodução com libmpv e interface egui.
- Descoberta de salas por multicast e broadcast IPv4, entrada manual e aprovação pelo anfitrião.
- Verificação dos arquivos, preparação dos dois players e início agendado.
- Sincronização de play, pause e seek, correção de desvio e reconexão.

## Downloads e instalação

Os dois pacotes são para x86_64 e não incluem o modo demo.

Arch Linux atualizado:

```sh
sudo pacman -U ./sync2gether-0.1.0-1-x86_64.pkg.tar.zst
```

Ubuntu 24.04:

```sh
sudo apt install ./sync2gether_0.1.0_amd64.deb
```

Os gerenciadores instalam as dependências, incluindo libmpv. Abra `sync2gether` pelo menu ou terminal. O seletor de arquivos precisa do portal do desktop e de um backend como `xdg-desktop-portal-gtk` ou `xdg-desktop-portal-kde`.

Confira a integridade dos downloads:

```sh
sha256sum --ignore-missing -c SHA256SUMS
```

O pacote Ubuntu requer 24.04; não é compatível com 22.04. O pacote Arch requer um sistema atualizado.

## Validação e limites

Os pacotes foram compilados e instalados em containers das respectivas distribuições. As verificações de Rust, os testes TCP e os testes com dois players libmpv usaram vídeos sintéticos, incluindo atraso e jitter de rede, pausa, seek, reconexão e arquivos diferentes.

A renderização OpenGL e a abertura e o fechamento do aplicativo instalado foram verificados com Xvfb e Mesa por software. O áudio dos testes usou uma saída virtual PulseAudio. Isso não comprova saída física de som, aceleração em GPU, execução em dois PCs ou comportamento em uma VPN real.

No libmpv antigo do Ubuntu 24.04, a renderização usa framebuffer RGBA16 para evitar vídeo preto no ambiente testado. HDR e fidelidade de cores dessa configuração não foram validados.

O modo demo permanece fictício e offline. O projeto ainda não define uma licença de distribuição ou de uso do código.
